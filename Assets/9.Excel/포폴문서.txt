프로젝트: 조각난 세계 (Shattered World)
1. 프로젝트 개요 (Project Overview)

장르: 3D 로그라이크 던전 탐험

개발 인원: 1인 개발

개발 기간: 2025.09.12 ~ 2025.11.14 (약 2개월)

플랫폼: PC

엔진: Unity

⭐ 핵심 특징 요약

던전 조각 배치 시스템: 획득한 던전 타일로 직접 던전 구조를 설계

점수 기반 보상·순환 루프: 탐험 → 점수 정산 → 던전 조각 및 영구 성장 아이템 지급

위험도 시스템: 입장·배치 수에 따라 난이도 증가 → 점수 보너스 증가

마을 경영: 건물 배치에 따라 NPC 기능 활성화(상점·식당·퀘스트)

요리 시스템: 조합 성공 시 레시피 해금, 일시·영구 능력치 증가

2. 게임 컨셉 (Game Concept)
세계관 요약

사라진 아버지를 찾아 도착한 ‘안개 끝 마을’.
플레이어는 조각난 던전과 마을을 복원하며, 그 과정에서 세계의 숨겨진 진실을 파헤칩니다.

플레이 메인 루프

던전 조각 획득 → 던전 설계 및 배치 → 탐험 및 성장 → 점수 정산 → 마을 확장

핵심 재미 요소

던전 설계의 전략성: 직접 배치하는 파밍 루트 설계

로그라이크의 반복과 영구 성장: 점수 정산 보상으로 영구 스탯·장비 확보

스토리·경영 결합: NPC 호감도, 마을 확장, 아버지의 행적 추적

3. 핵심 시스템 (Core Systems)
3-1. 던전 탐험 시스템
① 던전 배치 및 진입

건설 모드: 던전 액자 상호작용 → 설계 UI 진입

보유 던전 조각으로 타일을 배치하여 구조 생성

진입: 건설 종료 후 생성된 포탈로 바로 입장

② 몬스터 처치 및 보상

즉시 보상: 경험치 / 돈 / 드랍 아이템

점수: 몬스터 강함에 비례해 누적

던전 재화(파편): 정예 몬스터가 드랍

③ 점수 정산 및 추가 보상

던전에서 퇴장 시 총 점수 정산

점수에 비례해 영구 스탯 아이템 + 던전 조각 지급

조각은 던전 신규 타일 해금 및 배치에 사용

④ 위험도 시스템

던전 배치수/입장수에 따라 위험도 상승

레벨 상승 효과:

몬스터 스탯 증가

획득 점수 증가

초기화: 던전 조각을 소비해 레벨 초기화 가능

3-2. 전투 시스템 (Combat System)
기본 조작

좌클릭 → 기본 공격

우클릭 → 시점 고정 + 무기 사거리 시각 표시

회피/가드 없음 (무기 선택과 스킬 운용에 집중)

무기 시스템

근접(검): 광역 피해, 넉백 제공

원거리(완드): 단일 마법 피해, 자동 조준

인벤토리 UI에서 무기 교체 가능

스킬 및 성장

레벨업 시 스킬 포인트(SP) 획득

액티브 스킬 4종: 1~4번 슬롯, MP 소비, 쿨타임 독립

패시브 스킬 9종: SP로 영구 강화

3-3. 장비 시스템 (Equipment System)
장비 구성

슬롯 8개(무기/방패/헬멧/갑옷/장갑/신발/목걸이/반지)

등급

Common → Uncommon → Rare → Epic → Legendary
등급별로 추가 능력치 개수 0~4개 증가

세트 효과

3개 착용 → 1차 효과

6개 착용 → 2차 효과

효과는 생존 스탯 중심

획득 경로

몬스터 / 보물상자

던전 점수 보상에서 Rare 이상 꾸준히 지급

불필요 장비는 상점 판매

3-4. 요리 / 식당 시스템
레시피 해금

재료를 조합하여 요리 시도

성공하면 레시피 영구 해금

실패 시 재료 소모 → 실패작 지급

재료 획득

던전 채집

마을 상점 구매

요리 효과

일시적 능력치 증가(37종)

영구 능력치 증가(3종) — 희귀 재료 요구

이용 방식

식당 NPC와 상호작용 → 제작 UI 오픈

3-5. NPC 및 상호작용 시스템
마을 구성

던전과 동일하게 건물 배치 방식

건물 배치 시 해당 NPC 기능 활성화

NPC 종류

상점 NPC: 아이템 구매/판매

식당 NPC: 요리 제작

퀘스트 NPC: 처치/수집 퀘스트 제공

대화 전용 NPC: 몰입감 강화

호감도 시스템

대화/퀘스트 완료 시 호감도 상승

호감도에 따라 대사 변화

3-6. 저장 / 로드 시스템 (Save & Load System)

저장 방식

JSON 직렬화 기반(Newtonsoft.Json 사용)

플레이어 스탯, 인벤토리, 장비, 스킬, 해금 정보, 던전 조각, 마을 배치 등 핵심 진행 정보를 저장

게임 종료, 던전 퇴장 등 특정 이벤트에서 자동 저장 수행

ISavable 인터페이스를 구현한 모든 오브젝트를 SaveManager가 자동 탐색·관리하는 구조

로드 방식

메인 메뉴에서 즉시 불러오기 가능

세이브 파일 파싱 후 각 매니저(Player, Inventory, DungeonManager, VillageManager 등)에 값을 재전달

로드된 데이터는 메모리에 캐싱되며, 씬 로딩 이후 등장하는 오브젝트는 등장 즉시 자신의 데이터를 적용

데이터 구조 설계

ScriptableObject와 런타임 데이터를 분리하여 관리

세이브 파일에는 순수한 상태 데이터만 저장하고, 게임 진입 시 매니저들이 이를 재구성하는 방식

각 데이터는 고유 ClassName 기반(Dictionary)으로 저장되어 확장성 유지

순환참조 무시·정확한 타입 정보를 포함하는 직렬화 설정으로 복잡한 구조도 안정적으로 저장

안정성 및 최적화

필드 추가 시 기존 데이터와 충돌하지 않도록 선언적 구조 유지

던전·마을 배치는 좌표와 ID 등 최소 단위 데이터만 저장해 파일 크기 최소화

특정 객체만 저장하는 “부분 저장 기능”을 지원해 안정적인 진행 관리 가능

4. 콘텐츠 구성 (Contents)
1) 몬스터 (총 8종)

일반 몬스터 6종(토끼, 닭, 사슴, 산양, 늑대, 나무정령)

추격, 도주, 무리 행동, 속박 등 개별 AI 패턴

정예 몬스터 1종(곰)

주기적 광역 공격

보스 1종(거대 나무)

내려찍기, 가시 생성, 몬스터 소환

체력 감소 시 광폭화

2) 던전 (총 8종)

일반 던전 6종: 몬스터 분포에 따라 선택적 파밍

종합 던전 1종: 모든 몬스터 등장

자원 던전 1종: 보물상자 중심, 함정 다수 배치

3) 아이템·장비

아이템 60종: 소모템/요리/특수템(던전 조각) 등

장비 40종: 슬롯 8종 + 등급 5단계

4) NPC 및 요리

NPC 5명

요리 40종 (일시 효과 37, 영구 효과 3)
